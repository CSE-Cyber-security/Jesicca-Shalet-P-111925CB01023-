# Fibonacci Series

A Python program that prints the Fibonacci series for `n` terms.

## Project Structure

```
fibonacci-series/
├── data/            # sample input and expected output
├── src/             # source code (fibonacci.py)
├── tests/           # test cases
├── README.md
└── screenshot.docx  # screenshot of program output
```

## How to Run

```bash
python src/fibonacci.py
```

## Example

**Input:**
```
Enter the number of terms: 7
```

**Output:**
```
Fibonacci Series:
0 1 1 2 3 5 8
```

## Run Tests

```bash
python tests/test_fibonacci.py
```
